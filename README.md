# Achados Online

Vitrine responsiva de produtos e ofertas.

## Como usar

Abra `index.html` no navegador para visualizar o site.

## Como adicionar produtos

Abra `script.js` e adicione um novo objeto dentro de `products`:

```js
{
  image: "URL_DA_IMAGEM",
  category: "Casa",
  name: "Nome do produto",
  description: "Descrição curta do produto.",
  price: "R$ 00,00",
  link: "LINK_DA_SHOPEE_OU_MERCADO_LIVRE"
}
```

## Categorias

As categorias ficam no início do `script.js` e podem ser alteradas conforme necessário.

## Publicação

O projeto é estático e pode ser publicado no GitHub Pages, Netlify, Vercel ou outro serviço de hospedagem de sites estáticos.
